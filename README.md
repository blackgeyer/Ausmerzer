## English

Ausmerzer: A plugin that allows you to nerf the damage of specific weapons, reduce explosion damage (such as crystals), and restrict crafting or possession of certain items. This plugin will help if you are tired of modern-PvP heresy.

### Features:
* **No hardcode**: All messages, banned items, nerfed explosions etc. can be customized in config.yml.
Well, that's all...

### Technical compability
* **Core**: Any bukkit-based core or Folia
* **Version**: I tested this on versions 1.21.11 and 26.3, and everything worked great, but it might also work on version 1.20.5 — feel free to test it yourself.
* **Dependencies**: Adventure API (if your core doesn't have it)

### Installation
* **1.**: Download .jar file of it
* **2.**: Put it to `/plugins/` directory
* **3.**: Reload your server

## Russian

Ausmerzer — плагин, который позволяет нерфить урон конкретного оружия, снижать урон от взрывов (например, кристаллов) и ограничивать крафт или владение определенными предметами. Этот плагин поможет, если вы устали от ереси современного PvP.

### Возможности:

* **Никакого хардкода:** Все сообщения, запрещенные предметы, ослабленные взрывы и т.д. кастомизируются в `config.yml`.

Ну, вот и всё...

### Техническая совместимость

* **Ядро:** Любое ядро на базе Bukkit или Folia.
* **Версии:** Протестировано на версиях 1.21.11 и 26.3, всё работает отлично, но может работать и на версии 1.20.5 — смело проверяйте сами.
* **Зависимости:** Adventure API (если ваше ядро не содержит его «из коробки»).

### Установка

* **1.** Скачайте `.jar`-файл плагина.
* **2.** Поместите его в директорию `/plugins/`.
* **3.** Перезагрузите сервер.
